# React Calculator

A simple component-based calculator built using React and Vite.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Clear function
- Division-by-zero handling
- Responsive design

## React Concepts Demonstrated

- Functional components
- Props
- `useState`
- Event handling
- Component rendering with `.map()`
- State management

## Technologies

- React
- JavaScript
- HTML
- CSS
- Vite
- GitHub Pages

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to GitHub Pages

1. Change `base` in `vite.config.js` to match your repository name.
2. Install dependencies with `npm install`.
3. Run:

```bash
npm run deploy
```
